### 🧐 关于我

长期做开发者工具、AI 工具链和嵌入式 / 边缘 AI 项目。偏爱把真实使用中遇到的问题做成 CLI、MCP、自动化脚本或可复现的部署方案，并持续维护到真正能用。

- 🧩 **AI 基础设施**：维护 [MochiAPI](https://github.com/Subaru486desuwa/MochiAPI) 及配套接入工具
- 🖼️ **Agent 工具链**：用 [micu-image-mcp](https://github.com/Subaru486desuwa/micu-image-mcp) 把 Image2 生图、改图和多图参考能力接入 Claude Code / Codex / Cursor
- 🦯 **嵌入式与边缘 AI**：在 RK3588 上做 Linux + RT-Thread 双 OS 感知与实时决策，也做过 YOLO + RKNN 端侧部署
- 🦀 **Rust CLI**：用 TUI 和小工具解决会话监控、键鼠自动化等重复工作
- 📚 **ML / DL**：持续记录 PyTorch、Transformer、LoRA、Kaggle 与模型部署实践
